# 🤖 Introducción a Machine Learning con AutoML

Exploración práctica de herramientas de **Machine Learning Automatizado (AutoML)** para resolver problemas de predicción de forma rápida y eficiente.

## 🎯 Objetivo
Comparar el rendimiento (precisión, tiempo de entrenamiento) de modelos generados automáticamente frente a modelos ajustados manualmente.

## 🛠️ Tecnologías
- **Scikit-learn**: Para preprocesamiento y métricas.
- **AutoML Frameworks**: (H2O, TPOT, o similar según implementación).
- **Pandas**: Manipulación de datasets.

## 📊 Resultados Esperados
- Reporte comparativo de modelos.
- Notebooks reproducibles con el flujo de trabajo completo.
