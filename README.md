## 📂 Galería de Proyectos

### 🌟 1. [Chatbot Local con RAG y LLMs](./03-chatbot-local-streamlit-ollama)
**Tecnologías:** `Streamlit`, `Ollama`, `ChromaDB`, `LangChain` concept
> Sistema de chat inteligente que funciona 100% offline. Permite a los usuarios "chatear" con sus propios documentos PDF/DOCX utilizando modelos LLM locales como Llama 3 o Phi-3. Privacidad total y cero coste de API.

### 📈 2. [Predicciones de Machine Learning (AutoML)](./02-intro-ml-con-automl)
**Tecnologías:** `AutoML`, `Scikit-learn`, `Kaggle`
> Exploración de herramientas modernas de ML automatizado para resolver problemas de regresión y clasificación de forma eficiente, comparando el rendimiento contra modelos manuales.

### 🐍 3. [Fundamentos de Python para Data Science](./01-python-basico)
**Tecnologías:** `Python Pure`, `Algoritmos`
> Colección de scripts y notebooks que demuestran el dominio de las estructuras de datos, manipulación de archivos y lógica algorítmica esencial para cualquier Data Scientist.

## 🚀 Cómo usar este repositorio

Este portafolio está diseñado para ser reproducible. Cada sub-proyecto contiene sus propias instrucciones, pero puedes iniciar el entorno global así:

```bash
# 1. Clonar el repositorio
git clone https://github.com/RubenPA79/ml-portfolio-ruben.git

# 2. Instalar dependencias de desarrollo (Linters, Tests)
pip install -r requirements-dev.txt
```
